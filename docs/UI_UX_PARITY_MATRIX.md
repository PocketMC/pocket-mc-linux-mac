# PocketMC Windows -> Linux & macOS UI/UX Parity Matrix

**Authoritative Reference:** `pocket-mc-windows` (`docs/assets/screenshots/`)
**Target Repository:** `pocket-mc-linux-mac` (`main`)
**Updated After:** Phases 0-H implementation and Release build + automated test gate (`263 passed, 0 failed, 0 skipped`)

## Status Legend
- **Verified (Automated)**: ViewModels, services, routing, or control builders covered by automated xUnit tests alongside Release compilation; live desktop rendering still requires manual OS screenshot check where noted.
- **Implemented (Pending Visual Check)**: Rebuilt in Avalonia XAML matching Windows hierarchy, tokens, and controls, compiling cleanly in Release; awaiting side-by-side screenshot verification on target Linux and macOS desktops.
- **OS-Adapted**: Adjusted intentionally where Windows WPF APIs have OS-level equivalents or limitations (documented transparently).
